# Jankenpo no Rails

Aplicação pequena em Rails para jogar pedra, papel e tesoura.

## Gravação da execução

Há um vídeo mostrando o jogo em uso.

## Rotas

- Tela com o formulário: `/game/form`
- Processamento da escolha (não precisa ser aberta no navegador): `/game/play`

## Instalação

Instale as dependências com o comando de bundle.

## Subindo o servidor

Chame o servidor apontando para a porta 3000.

## Acessando

Com o servidor no ar, abra o navegador no endereço da máquina local na porta informada.
